FINDING 1 — libinput rejects the touchscreen outright:
  "libinput error: event1 - touchpanel: kernel bug: device has
   min == max on ABS_MT_WIDTH_MAJOR"
  FIX: /etc/libinput/local-overrides.quirks (guest/setup-input.sh):
    [OnePlus 7 touchpanel]
    MatchName=touchpanel
    AttrEventCode=-ABS_MT_WIDTH_MAJOR;-ABS_MT_PRESSURE
  RESULT: libinput list-devices now shows
    Device: touchpanel / Capabilities: keyboard touch        <-- GATE

FINDING 2 — udevd cannot run in the container (ConditionPathIsReadWrite=
/sys fails; /sys is ro) so libinput's udev backend sees no ID_INPUT_*
properties and ignores every device. FIX: dos-input-udevdb hand-writes
/run/udev/data/c13:NN from `udevadm test-builtin input_id` (works
daemon-less). Verified entries: c13:65 = ID_INPUT + ID_INPUT_TOUCHSCREEN.

FINDING 3 — THE pidfd HALF-BACKPORT (root cause of the "never phoc -E"
rule, now precisely diagnosed): this 4.14.357 kernel BACKPORTS
pidfd_open (syscall 434 returns a real fd) but NOT waitid(P_PIDFD)
(EINVAL). glib sees pidfd_open succeed, commits to the pidfd path, then
child-watch dispatch dies:
  WITHOUT shim: GLib-WARNING waitid(pid:301, pidfd=4) failed: Invalid
                argument ... CHILD-WATCH-FIRED status=-1   (bogus!)
  WITH    shim: CHILD-WATCH-FIRED status=0                 (correct)
  shim = /usr/local/lib/dos-pidfd-shim.so (guest/setup-input.sh):
  interposes syscall()/pidfd_open() -> ENOSYS; glib falls back to
  SIGCHLD. LD_PRELOADed into phoc + the phosh session by desktop-on.
  (LXC seccomp would be cleaner but our static lxc 4.0.12 lacks it.)

WLROOTS EVIOCGRAB HANDOFF (patch in guest/build-wlroots-phoc.sh, applied +
rebuilt): on every /dev/input/event* open, dup the fd and take EVIOCGRAB
in a detached 100ms-retry thread (grabs live on the open file
description). desktop-on kills the Android-side evgrab once phoc's
socket is up -> guest grab lands <=100ms later; no double-input window
beyond that. Compiles clean; prints "DecemberOS: EVIOCGRAB acquired" to
compositor.log per device.

seatd 0.9.1 active in guest (systemd unit enabled) — wlroots' libinput
backend needs a wlr_session (droidian-extensions is OFF in our build);
LIBSEAT_BACKEND=seatd exported by desktop-on.
