Gotchas re-confirmed this session:
  - `det shell 'a && b'` still splits at && on the device shell (su gets only
    a).  Same for $(...) — it expands as the adb shell user BEFORE su.
    Root multi-command = `adb shell su <<'EOF'` heredoc (det status style)
    or a dropped script.
  - det-hostagent consumes/deletes unknown files in run/control — don't use
    the control dir as a scratch file-drop path.
  - Re-running guest-start over adb hangs the client: the freshly spawned
    keeper/hostagent hold stdout.  Use setsid like `det on` does.
